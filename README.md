# GitHub Profile Finder

A React app that searches GitHub users and shows their profile and repositories, using the GitHub REST API.

**Live demo:** https://githup-founder-react.vercel.app

## Stack

- React 18 + Vite
- GitHub REST API
- English/Arabic interface (i18n)

## Features

- Search any GitHub username
- Profile card with avatar, bio and stats
- List of the user's public repositories

## Run locally

```bash
npm install
npm run dev
```
